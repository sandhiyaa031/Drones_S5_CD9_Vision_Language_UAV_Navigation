# Assets and licences of the urban disaster zone

**No external asset (mesh, texture, image, model) is used.** Everything that
makes up the disaster zone is generated by project code at build time, so
nothing is downloaded and nothing needs a third-party licence.

| Item | Source | Licence / status |
|---|---|---|
| Building facades, floor slabs, columns, rubble piles, beams, wrecks, ledges | `ros2_ws/scripts/disaster/make_disaster_zone.py` (procedural OBJ meshes: cell-grid facades, jittered boxes, convex hulls of random points) | project code |
| Surface textures (concrete, dark concrete, beige, masonry, rubble, rust, asphalt, dirt) | the same script (NumPy/OpenCV noise, stains, cracks, brick pattern), fixed random seeds | project-generated images |
| Survivor manikin, barrels, cone, tarp, crate and ball | `ros2_ws/scripts/village/make_village.py` (primitive shapes) | project code |
| UAV model, lidar | `ros2_ws/src/uav_autonomy/models_slam/`, derived from PX4's x500 model | PX4 model files are BSD-3-Clause |
| Gazebo Harmonic, ros_gz | installed from the ROS 2 Jazzy / OSRF packages | Apache-2.0 |
| PX4-Autopilot (unmodified) | `PX4-Autopilot/` | BSD-3-Clause |
| MuJoCo 3.16 (Python bindings), installed in `simulation/mujoco/.venv` | PyPI `mujoco` | Apache-2.0 |
| NumPy, SciPy, OpenCV, Matplotlib | system Python | BSD-type licences |

Generated files: `ros2_ws/src/uav_autonomy/models_disaster/dz_assets/`
(meshes and textures), `.../worlds/disaster*/` (world files). They can be
deleted and rebuilt with `python3 scripts/disaster/make_disaster_zone.py`.
The MuJoCo scenes copy the same textures to `simulation/mujoco/models/textures/`.

The scene is a fictional layout made for this project. It is inspired by
the look of earthquake-collapse photographs (concrete frames, pancaked floors,
rubble) but no photograph, map or real site is reproduced.
